# Advanced Innovation Charter Borough

Public site for the AICB project: a chartered territorial commons that combines historic English liberties, [Networked Commons Governance](https://networkedcommonsgovernance.org/), and the Guiting Power social model.

## Live

- Canonical: [https://www.charterborough.org](https://www.charterborough.org)
- Apex `charterborough.org` 308-redirects to `www`
- Vercel project: `aicb-website-6ha7`

## Stack

Next.js (App Router) and Tailwind CSS v4 — same family as `stumpyuk1/ncg-website`.

## Local

```bash
npm install
npm run dev
```

## What this site argues

- Britain’s binding constraint is institutional, not merely fiscal.
- A Royal Charter borough is a lawful opt-in sandbox: planning carve-out, civic covenant, pattern-book streets, compensatory precept to neighbours.
- NCG rules (sortition, liquid delegation, Forced Construction, trust audits) stop the sandbox becoming a captured company town.
- A Guiting-style Amenity Trust keeps a reserved housing stock and civic fabric for the people who work the place.
